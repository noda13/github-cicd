# 環境構築

## GitHub Cli セットアップ

- mac

```
$ brew install gh
```

- windows

```
$ winget install --id Github.cli
```

- コマンド

```sh
$ gh --version

$ gh auth login

$ gh --help

$ gh repo list

$ gh issue create

$ gh repo clone cli/cli

$ gh pr checkout 321

$ gh pr create --fill-first --web

$ gh pr --merge -m
```

---

## リポジトリの作成

```sh
$ gh repo create my-repo --public --clone --add-readme
```

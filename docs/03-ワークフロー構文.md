# ワークフロー構文

## コンテキスト

### コンテキストの種類

- github
- job
- runner
- matrix
- env
- jobs
- secrets
- needs
- vars
- steps
- strategy
- inputs

## 中間環境変数

- コンテキストはシェルコマンドへハードコードせず、環境変数を経由して渡す
- 環境変数はすべてダブルクォーテーションで囲む

## ステータスチェック関数

- success() 手前の処理が成功したらtrue
- failure() 手前の処理が失敗したらtrue
- cancelled() 手前の処理がキャンセルされたらtrue
- always()  手前の処理結果を問わず常にtrue
